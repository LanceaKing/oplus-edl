# 桌面工作区

从解包目录启动桌面应用，平台入口见[发布包与运行条件](distribution.md)。从源码运行时，在已缓存锁定依赖的工作区执行 `cargo run -p oplus-edl-desktop --locked --offline`。桌面与 CLI 共用设备服务和操作检查。当前原生平台验收和 USB 在途读取计时待实测。

## 连接与检查

1. 在左侧选择 USB 或串口，点击「发现设备」。USB 为默认后端。串口需要明确指定设备键或端口路径。
2. 选择设备、介质及加载器。如加载器需要配套材料，选择签名摘要和 DIGEST 签名。需要等待设备出现时，在「连接参数」中启用等待。
3. 点击「连接」，等待初始化完成。备份和恢复前，在中央区域点击「检查分区」。留空 LUN 范围时，服务根据设备报告扫描。可输入逗号分隔的 LUN 编号以限定范围。
4. 在表格中选择分区。筛选和排序保留选中项。「全选已读取分区」包含当前筛选隐藏的行。GPT 布局发生变化时，重新检查再选择。

同一会话刷新后，名称、条目和布局仍匹配的选择会映射到新快照。文件对话框选入的非 Unicode 路径以只读形式显示。要替换时重新浏览，或清空再输入完整路径。

健康会话可以继续用于后续操作。切换设备、介质或加载材料会释放旧会话。会话结束后，右侧保留最近结果。新连接需要再次点击「连接」。

## 备份、恢复和刷写

- **备份**需要分区选择和输出目录。成功的分区文件及 GPT 捕获会保留。失败的读取可能保留 `.partial`，它记录目前已收到的字节。
- **恢复**支持单镜像和备份目录。单镜像只选择一个目标分区。目录恢复可选择具体目标，也可明确选择范围内现有的全部映射。
- **XML 刷写**按界面中的 program、patch 文件顺序执行。用上移和下移调整顺序。核心保留文件内的节点顺序。
- **固件包**需要含 `IMAGES` 和 `META` 的原包。在 `META` 中查看 `super_def.<ID>.json`，按固件说明选择对应数字串，保留前导零。「仅离线准备固件包」生成 `selection.json`、XML 和 `super.img`。

复用准备产物时，选择「重开固件包」，输入原包、NV ID、已准备目录及准备时使用的刷写配置。核心检查产物绑定和 XML 操作，随后只读检查设备项目和写入范围。结果通过这些检查后，才显示本次写入确认。

刷写和恢复会显示一次写入摘要。检查目标、LUN、适用时的 slot、起始位置、传输长度、验证策略和后续动作，再选择「确认写入」或「取消」。表达式地址显示为未解析。确认仅对显示的准备任务有效。操作期间保持源文件稳定。输入变化会停止后续工作，并保留已确认的结果。

## 云端资产和安装身份

在「云端资产与安装身份」中选择配置与新的资产目录。配置内的 SWM 相对路径使用显式选择的基目录。已有安装身份会被复用。首次创建时，点击「创建安装身份…」，查看解析后的路径后确认。创建使用独占文件，已有身份保持原样。

「获取资产」使用独立工作槽。成功后可选择「使用已获取的资产」，将本地加载器、摘要和签名填入连接选项。需要在连接前自动获取时，勾选「连接时获取云端加载器」。失败或停止时，在结果中查看已保留的资产及本次创建的安装身份文件状态。

## 停止、关闭和诊断

底部的「停止」向工作线程发出协作停止请求。界面在该槽的下一任务开始前保留「已请求停止」。在终态中查看已确认写入、未完成验证和未知结果。若连接未完成，终态仍显示会话原因和已完成的初始化阶段。关闭窗口会等待在途操作到达终态并释放会话。设备重启仅在显式请求且前序检查允许时执行。

右侧分别保留最近的设备和离线结果。展开项目可查看写入确认、验证状态和字节计数。「清空」只清除显示日志。「导出诊断…」将阶段历史、终态事实和输出路径保存到本地。导出省略设备和服务返回的自由文本。

窗口设置和输入路径保存在应用的本地偏好文件。偏好记录包含所选云端基目录。身份文件保存在配置指定的位置，临时票据和审批留在任务内存。
